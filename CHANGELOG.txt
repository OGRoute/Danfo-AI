 DanfoAI — Changelog
 Branch: upgrade-r18
 Date:   2026-09-14 (fixes 2026-09-15)

-------------------------------------------------------------------------------
 FIXED — found while testing the running app (2026-09-15)
-------------------------------------------------------------------------------

  - INTRON_STT_URL / INTRON_TTS_URL set to Intron's wss:// streaming URLs made
    every Intron call fail ("fetch failed"): TTS returned 500 and voice input
    503. Non-http(s) overrides are now ignored with a warning.
  - Intron errors returned inside a JSON body (e.g. "insufficient balance to
    process the file") were read as silence. They are now errors; account
    problems are remembered for 10 minutes so the mic switches to the browser
    recogniser and explains why ("the Intron account is out of credit").
  - Clips under 1 s (rejected by Intron) are treated as no speech, and a pause
    no longer ends a phrase before 1.5 s of audio.
  - Intron TTS audio is served as audio/wav (the bucket says octet-stream).
  - Hydration error: FlipWords (a <div>) was nested inside a <p>.
  - Added a favicon (was a 404 on every page load).
  - The app stayed on a blank screen when Clerk's script couldn't load (slow
    or blocked connection to Clerk). After 8 s it now falls back to wallet and
    anonymous sign-in, and the sign-in card says Google/email is unavailable.
  - With real Clerk keys, clerkMiddleware no longer runs: nothing uses
    server-side auth(), and its handshake redirect made every first page load
    wait on Clerk's servers (214 s on a flaky connection, then a redirect
    loop). Keyless development mode still uses it.

-------------------------------------------------------------------------------
 FIXED — Voice input
-------------------------------------------------------------------------------

  - Listening no longer stops at the first pause. Recording continues until
    the rider taps stop, goes quiet for 30 s, or hits 5 minutes. Server engines
    get the audio phrase by phrase (split on pauses) so text appears while the
    rider is still talking; the browser recogniser is restarted automatically
    after its own short time-outs and shows live interim text.
  - Auto-detect now identifies Nigerian languages. The first phrase is
    transcribed by Intron's Pidgin, Yoruba, Igbo and Hausa models in parallel
    and the transcript that reads most like its own language wins
    (lib/language-detect.ts); the rest of the recording reuses that language.
  - Pidgin is sent to Intron's Pidgin-English model (pcm). The Intron widget
    and the browser recogniser can't be told to expect Pidgin, which is why it
    was failing; the widget is now opt-in (NEXT_PUBLIC_INTRON_WIDGET=1).
  - Needs INTRON_API_KEY. Without it the app says so and uses English.

-------------------------------------------------------------------------------
 ADDED
-------------------------------------------------------------------------------

  - Intron text-to-speech (/api/speak): native Yoruba, Igbo, Hausa, Pidgin
    and Nigerian-accented English voices, cached in memory; falls back to the
    browser voice, then YarnGPT.
  - Trip planner (lib/route-planner.ts): computes legs, boarding points,
    drop-offs, fares and times from the route database, including boarding
    mid-line, rail/ferry waits, up to two alternatives, and starting from the
    rider's GPS position. The model explains the plan instead of guessing, and
    a trip card under each reply shows the same numbers.
  - Reply guard: the chat model only rephrases the computed answer (English
    and Pidgin). A reply that drops a stop or fare, invents a price or loops
    is replaced by the computed answer. Trips asked in Yoruba, Igbo or Hausa
    are answered with the exact plan in English, because the only testnet
    chat model garbles those languages (MODEL_REPLY_LANGUAGES to change).
  - Route database v2: 46 routes / 43 stops — LAMATA BRT corridors, Blue Line
    and Red Line rail, Ikorodu ferry and major danfo routes, with 2026 fares,
    journey times, boarding points and aliases in all five languages.
  - Live map: routes drawn on real roads (OSRM via /api/directions), live GPS
    dot with heading and accuracy, follow mode, step-by-step progress, next
    stop and ETA, route options, dark map tiles, and a "Simulate trip" demo.
  - Theme picker with Light, Dark and System (follows the OS live).
  - Clerk sign-in embedded on the landing screen (Google, email, …) with a
    UserButton in the header. Runs in Clerk keyless mode during development,
    so it works before you create Clerk keys.
  - Message box is an auto-growing textarea (Enter sends, Shift+Enter adds a
    line).

-------------------------------------------------------------------------------
 FIXED — 0G Compute funding (correction to r17)
-------------------------------------------------------------------------------

  - r17 read balances with broker.ledger.getLedgerWithDetail(), which doesn't
    exist in @0glabs/0g-serving-broker 0.6.5. The read always failed, so every
    server restart deposited and transferred another ~0.55 0G. Balances are
    now read with inference.getAccount() / ledger.getLedger().
  - The SDK's own auto top-up (it targets 2,000,000 × token price ≈ 8.8 0G for
    the testnet chat model) is switched off; the app tops the sub-account up
    to 0.5 0G when it falls below 0.2 0G (contract minimum is 0.1 0G).
  - 0G Whisper now shares the funded broker and calls processResponse().
  - Replies use up to 900 tokens at temperature 0.3, and only the relevant
    routes are sent in the prompt.

-------------------------------------------------------------------------------
 CHANGED — 0G Compute cost: ~1.1 0G → under 0.6 0G per provider
-------------------------------------------------------------------------------

  - The 0G SDK (@0glabs/0g-serving-broker) auto-transfers a full 1 0G into a
    provider sub-account whenever it doesn't exist or is empty — that was the
    source of the ~1.1 0G startup cost.
  - lib/zg-compute.ts now pre-funds each provider sub-account to 0.5 0G
    (COMPUTE_MIN_BALANCE_OG) with a 0.55 0G top-up target
    (COMPUTE_TARGET_BALANCE_OG) BEFORE the first acknowledge/inference call,
    so the SDK's 1 0G auto-transfer never fires. Total wallet spend per
    provider is now ~0.555 0G + gas.
  - .env.example funding docs updated to match.

-------------------------------------------------------------------------------
 ADDED — Intron Sahara streaming speech-to-text (primary voice input)
-------------------------------------------------------------------------------

  - Integrated @intron_health/intron_transcriber_streaming (Intron's streaming
    ASR widget) as the primary voice input. Intron is built for African
    accents and natively supports Yoruba, Igbo, Hausa, English and Nigerian
    Pidgin.
  - New components/IntronVoiceInput.tsx: loads the widget client-side,
    captures live partial transcripts via the widget's document events
    (intronInferEventStreamTextReceived / intronInferEventTranscriptResult)
    and feeds them into the chat input's React state (the widget never writes
    into the DOM behind React's back).
  - Enabled by setting NEXT_PUBLIC_INTRON_API_KEY (voice.intron.io → View
    Integration). When set, the widget's record button replaces the built-in
    mic. Falls back cleanly: browser Web Speech → local Whisper → server-side
    Intron file API → 0G Whisper (all unchanged).
  - The model version (Sahara) is managed Intron-side; the package exposes no
    model selector.

-------------------------------------------------------------------------------
 CHANGED — Route answers always include price + boarding location
-------------------------------------------------------------------------------

  - lib/prompt.ts: ANSWER RULES now require every route reply to include, in
    order: (1) the route + exact boarding point (park/terminal/bus stop),
    (2) the approximate fare in ₦ (per leg for multi-leg trips), (3) the
    change point for multi-leg trips.
  - data/lagos-routes.json: every seed route now carries a `board` field with
    the specific park/stop where the vehicle is boarded (e.g. "CMS danfo park,
    under the bridge by Tafawa Balewa Square"). Re-run `npm run seed` and
    update ROUTES_ROOT_HASH to push the richer KB to 0G Storage.

 DanfoAI — Changelog
 Branch: upgrade-r16
 Date:   2026-07-03
===============================================================================

Conversational Nigerian transit agent for Lagos danfo/BRT routes, on 0G.
This changelog covers the features and fixes added on top of the base app.


-------------------------------------------------------------------------------
 ADDED — Features
-------------------------------------------------------------------------------

Authentication & sessions (Clerk)
  - Hosted sign-in via Clerk (Google, email magic link, etc.), JWT sessions,
    no database required. Clerk is optional — if its keys are absent the app
    still runs on wallet + anonymous.
  - Wallet sign-in (Web3 / MetaMask) via ethers BrowserProvider.
  - "Continue without an account" (anonymous) path — no sign-in required.
  - Unified auth context: Clerk -> wallet -> anonymous priority.
  - Middleware is guarded so the app runs with or without Clerk configured.

Chat history
  - Per-account conversation history (persisted for signed-in identities,
    ephemeral for anonymous). Slide-in history drawer: new chat, select,
    delete, plus account / sign-out footer.

Notifications
  - Header bell with unread badge and dropdown panel; fires on verified
    replies / errors; persisted per identity.

Dark / light mode
  - CSS design tokens for both themes, no-flash theme script, system-preference
    default, header toggle. Theme-aware throughout.

Responsive UI
  - Tablet / phone / narrow breakpoints across the whole app.

Accessible transit background
  - Decorative animated danfo bus, car and okada on a subtle road; aria-hidden,
    low-contrast, respects prefers-reduced-motion.

Animated multilingual greeting + logo (merged from benji branch)
  - FlipWords greeting cycling E kaabo / Nnoo / Barka / Welcome (framer-motion),
    rendered theme-safe. DanfoAI bus logo in the header with a themeable
    wordmark (black on the light header, yellow on the dark header).

Route map (Leaflet + OpenStreetMap)
  - Full-screen map plotting Lagos stops; highlights and draws the route
    detected from the current conversation. No API key; code-split so it loads
    only when opened.

Voice-to-text (speech-to-text)
  - Primary: the browser Web Speech API (instant, on-device, zero server load).
  - Fallbacks: local Whisper service, then Intron, then 0G Whisper.
  - Language picker (Yoruba / Igbo / Hausa / English / Pidgin) drives the
    recognizer language.

Text-to-voice (text-to-speech)
  - Primary: the browser speechSynthesis (instant, zero server load).
  - Fallback: YarnGPT service (Nigerian-accented voice; slower on CPU).
  - "Listen" button on each assistant reply.

Local speech service (yarngpt-service)
  - FastAPI service bundling:
      * YarnGPT2 text-to-speech (English, Yoruba, Igbo, Hausa, Pidgin).
      * Whisper speech-to-text via faster-whisper (auto-detects language).
  - Endpoints: /health, /tts, /stt.
  - Config via yarngpt-service/.env (model sizes, preload, timeouts, etc.).


-------------------------------------------------------------------------------
 CHANGED
-------------------------------------------------------------------------------

  - Voice-in and voice-out default to the browser speech engines for speed
    (instant, no CPU/RAM load); the neural services are automatic fallbacks.
  - Whisper STT tuned for low-RAM hardware: lazy model load (no startup OOM),
    "tiny" model default, faster-whisper (int8), beam search, VAD, a Lagos
    transit domain prompt, all CPU cores.
  - YarnGPT TTS: startup preload option, in-memory clip cache, capped spoken
    text length, soundfile WAV encoding, all CPU cores.
  - Themeable DanfoAI wordmark; enlarged, responsive header logo.
  - Chat responses capped (max_tokens) to reduce 0G Compute token spend.


-------------------------------------------------------------------------------
 FIXED
-------------------------------------------------------------------------------

  - Connect-wallet button: connects on eth_requestAccounts alone (one popup)
    instead of an extra, unverifiable signature step; clearer no-wallet message.
  - 0G Compute ledger funding: funds the per-provider sub-account to the network
    minimum (deposit -> transferFund), idempotently; falls back to depositFund
    when the ledger already exists ("Account already exists"); clear error when
    the wallet lacks testnet 0G.
  - 0G RPC timeouts: shared, tuned provider (static network + explicit timeout)
    across all 0G libs.
  - TTS "Couldn't play audio." shown after normal playback: detach media
    handlers before clearing the source.
  - /api/speak fetch: undici dispatcher with a long timeout for slow CPU
    inference; used undici's own FormData/fetch to avoid a version clash.
  - /api/transcribe: correct multipart to the local STT service; engine
    ordering with an STT_PREFER_INTRON toggle.
  - Dark-mode logo legibility.
  - Speech service stability on low-RAM hardware (lazy load avoids OOM kills).


-------------------------------------------------------------------------------
 SECURITY

-------------------------------------------------------------------------------
 KNOWN LIMITATIONS
-------------------------------------------------------------------------------

  - Hardware: on a low-power CPU-only laptop (e.g. i5-6200U / 8 GB, no GPU),
    neural TTS/STT are slow and can exhaust RAM. Browser speech engines are used
    by default to keep voice fast and stable; the neural services are optional.
  - Nigerian-language STT accuracy: browser recognition and Whisper are weak for
    Yoruba/Igbo/Hausa. Best accuracy needs Intron (pending account approval) or
    a cloud STT (e.g. Google), or a bigger machine to run Meta MMS / larger
    Whisper.
  - Intron STT: the current account returns 403 (needs integrator approval,
    voice@intron.io); wired as a fallback and behind STT_PREFER_INTRON.
  - 0G testnet: the public RPC is slow, and no speech provider is online.


-------------------------------------------------------------------------------
 SETUP NOTES
-------------------------------------------------------------------------------

  App:
    - Copy .env.example to .env.local and fill in values (never commit .env.local).
    - npm install; npm run dev.

  Speech service (optional — only needed as a fallback / for the Nigerian voice):
    - See yarngpt-service/README.md. Requires a Python 3.11 env with the deps
      above, ffmpeg, the cloned yarngpt package, and the WavTokenizer + Whisper
      model files (downloaded on first use / per the README).
    - Run: uvicorn main:app --host 0.0.0.0 --port 8000
    - Point the app at it with YARNGPT_API_URL (defaults to http://localhost:8000).
